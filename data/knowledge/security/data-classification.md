# Data Classification and Handling

Acme uses four classifications: Public, Internal, Confidential and Restricted. Restricted data must be encrypted in transit and at rest and shared only with explicitly authorised recipients. Confidential and Restricted data must not be copied to personal email or consumer file-sharing services.
