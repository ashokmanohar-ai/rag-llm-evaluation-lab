# Password Reset Procedure

Employees should reset a forgotten password at https://password.acme.example using the self-service verification flow. The service desk never asks for an existing password or MFA code. If self-service verification fails, contact the service desk and quote the device asset number. Temporary passwords expire after 30 minutes.
